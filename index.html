Creating a portfolio website on GitHub is one of the best and completely free ways to showcase your projects to potential employers or clients. There are two main ways to do this: The Easy Way: Using a free template (HTML/CSS) and hosting it on GitHub Pages. The Automated Way: Using GitHub Pages with a site generator or GitHub Profile README (which isn't a full website, but serves as a great landing page). Here is a step-by-step guide to setting up a classic, professional portfolio website using the Easy Way (GitHub Pages). Step 1: Create a GitHub Account If you don't have one already, go to github.com and sign up for a free account. Step 2: Create a New Repository Log in to GitHub. In the top-right corner, click the + icon and select New repository. Name your repository following this strict format: your-username.github.io (Replace your-username with your actual GitHub username, e.g., johndoe.github.io). This is crucial because GitHub automatically recognizes this naming convention to host your website. Set the repository to Public (private repositories require GitHub Pro for Pages, whereas public ones are free). Check the box that says Add a README file. Click Create repository. Step 3: Get a Portfolio Template Writing a website completely from scratch can take time, but there are hundreds of free, pre-made HTML/CSS portfolio templates available. Search online for "free developer portfolio templates HTML CSS" or check out sites like HTML5 UP, Start Bootstrap, or search GitHub for "portfolio template". Download your chosen template. It will usually contain files like index.html, a css folder, an images folder, etc. Step 4: Upload Your Files to GitHub There are two ways to get your portfolio files onto your new repository: Option A (Directly through the browser): Go to your newly created repository (your-username.github.io). Click on the Add file dropdown button and select Upload files. Drag and drop all your website files (index.html, stylesheets, folders, etc.) directly into the browser. Make sure your main homepage file is named index.html (all lowercase). GitHub Pages looks for index.html to load the site. Click Commit changes. Option B (Using Git on your computer - Recommended for developers): Clone your repository to your local machine: Bash git clone https://github.com/your-username/your-username.github.io.git Move your portfolio files into that folder. Push the files back to GitHub: Bash git add . git commit -m "Add portfolio website" git push origin main Step 5: Enable GitHub Pages If your files are uploaded correctly, GitHub Pages is usually enabled by default, but it's good to verify: Go to your repository on GitHub and click on the Settings tab (near the top right). In the left sidebar, look for the Code and automation section and click on Pages. Under Build and deployment > Branch: Ensure it is set to Deploy from a branch. Select the branch (usually main or master) and keep the folder as / (root). Click Save. Step 6: View Your Live Website! Wait about 1 to 2 minutes for GitHub to build and deploy your site. Open a new browser tab and go to: [https://your-username.github.io](https://your-username.github.io) Congratulations! Your portfolio is now live on the internet. Whenever you want to update it, just push or upload your changes to that same repository. Alternative: The "GitHub Profile README" (Bonus) If you want a quick landing page directly on your GitHub profile without managing an index.html file: Create a new public repository with the exact same name as your username (e.g., if your username is janedoe, name the repo janedoe). Make sure to check Add a README file. GitHub will display this README.md file right on your main profile page.
